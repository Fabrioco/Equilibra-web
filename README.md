# ⚖️ Equilibra – Personal Finance App

Equilibra é uma plataforma SaaS de gestão financeira individual, focada em proporcionar clareza, organização e controle absoluto sobre o seu dinheiro. Desenvolvido com uma estética minimalista e moderna, o app transforma a complexidade das finanças em uma experiência simples e intuitiva.

## 🚀 Getting Started

Este é um projeto Next.js bootstrapped com `create-next-app`.

### Prerequisites

- Node.js 18.x ou superior
- NPM, PNPM ou Bun

### Installation

```bash
git clone https://github.com/seu-usuario/equilibra.git
cd equilibra
npm install
```

### Running the App

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar a aplicação.

## ✨ Features

- **Fluxo de Caixa Individual**: Registro completo de receitas e despesas com categorização inteligente
- **Projeção de Gastos**: Sistema de transações fixas e recorrentes para prever seu saldo
- **Parcelamentos**: Gestão automática de compras parceladas
- **Modo Privacidade**: Atalho para ocultar valores sensíveis
- **Metas Financeiras**: Acompanhamento de objetivos de economia
- **Dashboard**: Resumo mensal de desempenho financeiro

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Phosphor Icons
- **State Management**: React Context API
- **Language**: TypeScript
